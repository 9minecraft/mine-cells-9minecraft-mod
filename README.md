# Mine Cells — Survive Brutal Roguelike Dungeon Runs

Mine Cells 9minecraft Mod rebuilds the world of Dead Cells inside Minecraft: not as a minigame or an arena, but as a set of full dimensions you travel to, fight through and come back from. Step through a doorway portal and you leave the overworld behind for the Prison, the Promenade of the Damned, the Ramparts or the Black Bridge, each generated as a proper hand-designed layout rather than scattered rooms. The dimensions are built out of a room grid, so they read like real places.

## What this build is

An unofficial rebuild of **mim1q**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
